## 읽을 때 주의

- **개발 세트 수치다.** 규칙 두 개(업로드 판정, 확인 요청 범위)를 이 13개 앱을 보며 고쳤다. 공정한 정확도는 규칙을 만들 때 보지 않은 앱(held-out)으로 다시 재야 한다.
- **정답(apps.json)은 초안이다.** `reviewed_by`가 비어 있는 동안은 이진서가 검토하기 전 값이다.
- **확인 후 100%는 상한이다.** 확인 요청된 항목을 개발자가 모두 바르게 고친다고 가정한 값이다. 확인 요청을 받지 않은 오답(online-boutique의 data)은 고쳐지지 않는다.
- 남은 오답: etherpad의 큰 파일(가져오기용 업로드 라이브러리를 대용량 업로드로 판정), uptime-kuma의 DB(드라이버 5개 중 기본값이 SQLite인 것은 코드 구조만으로는 알 수 없음, 확인 요청함), online-boutique의 DB(멀티 서비스라 범위 밖).
